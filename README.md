# Retro Galaxy

Retro Galaxy is a cosmic neon arcade with seven fast mini-games built for quick retro fun. The project is packaged as a single HTML game hub with mobile controls, desktop keyboard support, responsive layouts, visual themes, and performance-friendly options.

## Creator

Created by Vaishnav.

Contact: vaishnavr1k@gmail.com

## Vision

The vision for Retro Galaxy is to feel like a pocket-sized neon arcade: simple to open, fast to play, and polished enough to work across phones, tablets, and desktop screens. Each game should be easy to understand, responsive to input, and visually playful without sacrificing performance.

## Games

- Neon Snake
- Cosmic Pong
- Galaxy Shooter
- Astro Runner
- Crystal Breakout
- Rainbow Bird
- Alien Slingshot

## Use Cases

- Quick casual play sessions on mobile or desktop.
- A single-file arcade demo for sharing or hosting anywhere.
- Touch-control testing across portrait and landscape devices.
- A creative playground for experimenting with retro visual effects, sound, and mini-game mechanics.
